====================================================
           STUDENT PRODUCTIVITY TRACKER
====================================================
           React · Node.js · Capacitor · Local Storage
====================================================

A productivity companion app designed exclusively for students to
plan goals, track study routines, manage tasks, and view performance
analytics — all in a modern cyberpunk/hacker UI theme.

====================================================
FEATURES
====================================================
1️⃣ Dashboard Analytics
    - Productivity graphs with React ApexCharts
    - Smart suggestions for best study time slots

2️⃣ Task Manager
    - Add, edit & complete tasks easily

3️⃣ Routine Planner
    - Schedule & maintain consistent study habits

4️⃣ Goal / Syllabus Setup
    - Add subjects & track progress visually

5️⃣ Health Focused
    - Hydration & wellness reminders for students

6️⃣ Android App Support
    - Fully deployable on real Android devices with Capacitor

====================================================
TECH STACK
====================================================
#### Frontend:
    • React (SPA)
    • React Router DOM
    • Custom Cyberpunk CSS theme

#### Charts:
    • React ApexCharts

#### State Management:
    • Context API (SyllabusContext, HealthContext)

#### Backend:
    • Node.js + Express (Runs independently in /Backend)

#### Mobile Deployment:
    • Capacitor + Android Studio

#### Storage:
    • LocalStorage helper functions

====================================================
HOW TO RUN FRONTEND  (WEB VERSION)
====================================================
#### 
	npm install
	npm start
	npm run build

====================================================
HOW TO RUN BACKEND SERVER
====================================================
#### 
	cd Backend
	npm install
	node.server.js

#### 
	Ensure backend URL is reachable by Android:
	Example → http://YOUR_LOCAL_IP:5000/

====================================================
DEPLOY TO ANDROID (REAL DEVICE)
====================================================
####    
	npx cap sync android
	npx cap open android

Then build & run from Android Studio
(USB debugging enabled)
